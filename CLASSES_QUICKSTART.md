# Класи - Швидкий старт

## 🎓 Phase 1 (MVP) - Готово!

Базова система класів для групових занять.

### ✅ Що вже працює:

1. **Створення та управління класами** (тільки admin)
   - Створити клас
   - Редагувати назву/опис
   - Архівувати клас

2. **Управління студентами**
   - Додати студента за username
   - Видалити студента
   - Студент може вийти з класу

3. **Приєднання до класу**
   - Публічні класи з invite code (формат: ABC-123)
   - Студент вводить код і автоматично приєднується

4. **UI сторінки**
   - `/classes` - Список класів (фільтри: як викладач/студент/всі)
   - `/classes/new` - Створити клас
   - `/classes/join` - Приєднатися за кодом

### 📋 Перший запуск:

1. **Створити індекси в MongoDB:**
   ```bash
   npx tsx scripts/init-class-indexes.ts
   ```

2. **Увійти як admin** (тільки admin може створювати класи в Phase 1)

3. **Створити тестовий клас:**
   - Зайти на `/classes`
   - Натиснути "Створити клас"
   - Заповнити форму:
     - Назва: "Польська А1 - Група 1"
     - Опис: "Тестова група для початківців"
     - ✅ Публічний клас (згенерується invite code)
     - Мова: Українська

4. **Додати студентів:**

   **Варіант А: Через username (викладач)**
   - Відкрити клас
   - Перейти на вкладку "Студенти"
   - Ввести username студента
   - Натиснути "Додати"

   **Варіант Б: Через invite code (студент)**
   - Студент заходить на `/classes/join`
   - Вводить код (напр. ABC-123)
   - Автоматично приєднується

### 🔧 API Endpoints

```typescript
// Classes
GET    /api/classes                # Мої класи
POST   /api/classes                # Створити клас
GET    /api/classes/[id]           # Деталі класу
PATCH  /api/classes/[id]           # Оновити клас
DELETE /api/classes/[id]           # Архівувати клас

// Students
GET    /api/classes/[id]/students           # Список студентів
POST   /api/classes/[id]/students           # Додати студента
DELETE /api/classes/[id]/students/[userId]  # Видалити студента
POST   /api/classes/join                    # Приєднатися за кодом
```

### 📊 Database Collections

```
classes              - Інформація про класи
class_assignments    - Завдання (Phase 2)
class_submissions    - Здачі робіт (Phase 2)
```

### 🎯 Приклад використання:

**Сценарій: Викладач створює клас для групи**

1. **Admin створює клас:**
   ```
   Назва: "Польська для IT - Осінь 2026"
   Опис: "Інтенсивний курс для програмістів"
   Публічний: Так
   → Згенерований код: KRT-456
   ```

2. **Admin діліться кодом зі студентами:**
   ```
   "Приєднуйтесь до класу за кодом: KRT-456"
   ```

3. **Студенти приєднуються:**
   - Анна заходить на /classes/join
   - Вводить KRT-456
   - → Успішно приєдналася!

4. **Викладач бачить список:**
   - Клас: "Польська для IT - Осінь 2026"
   - Студенти: Анна, Петро, Марія (3)
   - Готовий для Phase 2 (завдання)
